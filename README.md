# 跟读课堂 Book 4

面向学生的逐句英语跟读练习页，以及 macOS 下载包。

## 学生开始使用

打开本仓库启用 GitHub Pages 后生成的网页链接，即可开始练习。首次录音需要在浏览器中允许麦克风。

Mac 用户也可以从 `downloads/Follow-Classroom-Book4-Mac.zip` 下载 App 压缩包。解压后将 App 放入“应用程序”并打开。

## 功能

- 逐句跟读与复述
- 英文示范发音后自动开始跟读录音
- 句子下方显示中文提示
- 慢速播放、单句循环、回听自己的录音
- 综合评分、流利度估算、准确度和完整度提示
- 按学生导出/导入跟读记录

## 评分与数据

评分根据浏览器语音识别转写和目标句子的匹配度估算，不是专业音素级发音诊断。成绩保存在当前设备的浏览器中，不会自动上传。录音仅临时保存在页面中，刷新或关闭页面后会清除。

## 隐私

网页需要浏览器麦克风权限。部署到 GitHub Pages 后，学生访问网页时需要各自在浏览器中允许麦克风。请勿把学生个人信息录入软件。
